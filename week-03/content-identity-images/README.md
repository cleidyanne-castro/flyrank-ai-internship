# Week 3: Map It and Give It a Face

I turn complex business data into reliable data and AI systems that people can use.

## Identity kit

Fonts:

- Heading and interface text: Arial with strong weight and tight tracking.
- Editorial emphasis: Georgia italic for the short contrast line.
- Body copy: Arial with increased line height for readability.

Palette:

- Midnight: #0b1024
- Near-white: #f5f7ff
- Cobalt: #8ea2ff
- Violet: #7b61ff
- Muted blue: #4d5875

Logo:

The portfolio uses the text mark CC. as a small wordmark.

Style note:

The interface is quiet and technical, with a midnight base, cobalt and violet accents, large headings, and enough space for the project descriptions to breathe. The work should be more memorable than the decoration.

## Image curation

The portfolio uses one connective hero visual that suggests data and AI systems. Project cards use real repository links instead of invented screenshots.

Rejected image note:

I rejected a softer pastel illustration because it looked attractive but did not signal data engineering or AI clearly enough. The final visual uses a darker technical direction and works better with the proof statement.
